# Fund letterheads

Each fund has a full-page official letterhead scan (`<slug>_letterhead.png`):

| Fund               | Source scan                        |
|--------------------|------------------------------------|
| Fund 1             | `fund_1_letterhead.png`            |
| Fund 2             | `fund_2_letterhead.png`            |
| Fund 3             | `fund_3_letterhead.png`            |
| Fund 4             | `fund_4_letterhead.png`            |
| Continuation Fund  | `continuation_fund_letterhead.png` |
| AMC                | `amc_letterhead.png`               |

The header (top 3.75 cm) and footer (bottom 2.75 cm) strips
(`<slug>_header.png` / `<slug>_footer.png`) are cropped from that scan.
Replace a scan and the strips are regenerated automatically.
`fund_1_source.pdf` is only used as a fallback when a scan is missing.

Operators can drag, select, and drop the header and footer strips on the page.
